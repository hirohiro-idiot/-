# MyTimerGame v0.3 — 指定時刻の音声再生

既存のv0.2の文章編集・タイマー・イベント編集はそのまま利用できます。

## 追加手順
1. 音声ファイル（例: voice01.mp3）を `audio/` にアップロード。
2. `config/audio.js` をGitHub上で編集。
3. `cues` のコメント行の `//` を外し、秒数とファイル名を設定。
4. 変更をコミットしてGitHub Pagesの更新を待ち、ページを再読み込み。

例（開始30秒後と90秒後に再生）:
```js
cues: [
  { at: 30, file: "audio/voice01.mp3", enabled: true },
  { at: 90, file: "audio/voice02.mp3", enabled: true },
]
```

`onStart`, `onFinish`, `onEvent` に音声ファイル名を入れるとそれぞれ開始・終了・ランダムイベント時に再生します。`null` なら無効。

## 動作上の注意
- 指定時刻は**開始からの経過秒数**です。残り時間ではありません。
- 同時に複数の音声が発生すると後から再生するものが前の音声を停止します。
- 一時停止中は音声も一時停止し、再開時に続きから再生します。
- ブラウザがバックグラウンドになるとタイマーは経過しますが、音声の正確な再生は保証されません。
- 初回の再生はユーザーが「スタート」を押して開始してください。モバイルでは自動再生制限があります。
- `config/texts.js` で従来どおり文章を編集できます。
- 音声ファイルはGitHubの公開リポジトリから誰でも取得できます。個人情報や公開権限のない音声は置かないでください。

## GitHubへの反映
ZIPを展開し、フォルダの**中身**をリポジトリ直下に上書きアップロードしてください。既存のファイルと同名なら更新してください。
